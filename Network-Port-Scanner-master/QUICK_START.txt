❓ COMMON QUESTIONS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Q: Do I need to install anything?
A: No! Python 3.7+ is all you need. All dependencies are built-in.

Q: Which version should I use - CLI or GUI?
A: GUI for ease of use, CLI for scripting/automation.

Q: How long does a full scan take?
A: All 65535 ports: 5-30 minutes (depends on network).

Q: Why are some ports showing as closed?
A: Either the service isn't running or firewall is blocking.

Q: Can I scan the internet?
A: Technically yes, but legally NO without permission!

Q: What does "banner grabbing" do?
A: Reads the service banner (e.g., Apache/2.4.6).

Q: How do I speed up scans?
A: Increase threads, reduce timeout, use Quick Scan mode.

Q: Is this tool free?
A: Yes! It's open source and educational.

Problems? Try these steps:

❌ "Python command not found"
   → Install Python from python.org
   → Check PATH environment variable
   → Restart terminal after installation

❌ "GUI window won't open"
   → Run: python -m tkinter (to test)
   → On Linux: sudo apt install python3-tk
   → On Mac: Install Python from python.org

❌ "Permission denied"
   → Windows: Run as Administrator
   → Linux/Mac: Use: sudo python3 main.py

❌ "No open ports found"
   → Check firewall settings
   → Try port 80 or 443 first
   → Increase socket timeout

❌ "Module not found error"
   → All files must be in same directory
   → Check for typos in filenames

For more help: See README.md or FILE_GUIDE.md
